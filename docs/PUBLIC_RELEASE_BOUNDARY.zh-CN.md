# 公开发布边界

这份源码发行版在没有 TMCRA 基础设施的情况下也必须可用。仓库克隆包含记忆算法、本地 API、本地存储、模型选择策略、公开推理权重、benchmark 复现、测试，以及安装、启动和卸载工具。

以下内容明确排除：

- 线上账号、订阅、额度、支付与计费系统；
- 员工后台、租户管理、生产队列、告警和部署自动化；
- 生产域名、主机地址、凭据、Key 池、数据库连接和真实环境文件；
- 私有用户数据、生产记忆数据库、请求日志与原始运维日志；
- 私有训练语料、训练机器路径和可恢复的优化器或运行状态；
- 官网源码与桌面安装包二进制文件。

本地运行时不能导入生产服务模块，也不能静默回退到 TMCRA 线上接口。公开监听地址固定为 `127.0.0.1`。只有用户明确填写接口和凭据时，生成请求才允许离开本机。

`PUBLIC_RELEASE_MANIFEST.json` 定义允许的顶层目录和必须存在的运行文件。`scripts/audit_public_release.py` 会检查当前发布树中的边界越界、生成状态、高置信凭据、生产主机、内部机器路径和生产服务导入；`--history` 还会扫描可达 Git 历史，并且不会输出命中的敏感值。

自动扫描是发布门禁，不等于对任意文本“绝对没有秘密”的数学证明。每次公开推送前仍需人工检查 staged diff、模型清单、第三方许可与最终归档文件。
